## 🚀 Local Development

```bash
# Clone repository
git clone https://github.com/CapMorningStar/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
